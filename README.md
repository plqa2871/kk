# زر K العائم (FloatingK)

زر عائم على الشاشة، لما تضغطه يرسل ضغطة حرف **K** للتطبيق المفتوح (عبر `input keyevent KEYCODE_K`)
بصلاحيات Shizuku أو الروت. اسحب الزر لتحريكه.

## البناء
**الطريقة 1: Android Studio (على كمبيوتر)**
افتح مجلد المشروع، انتظر Sync، ثم Build > Build APK(s). الملف يطلع في `app/build/outputs/apk/debug/`.

**الطريقة 2: GitHub Actions (مجاني، بدون برامج)**
ارفع محتويات المجلد على مستودع GitHub جديد، ثم تبويب Actions > Build APK > Run workflow.
بعد ما يخلص نزّل `FloatingK-apk` من قسم Artifacts.

## الاستخدام
1. ثبّت التطبيق وأعطه صلاحية "العرض فوق التطبيقات".
2. Shizuku: ثبّت تطبيق Shizuku وشغّله (الأندرويد 11+: من خيار Wireless debugging)، ثم اضغط "طلب صلاحية Shizuku".
   أو اختر وضع "روت" وامنح صلاحية su.
3. اضغط "تشغيل الزر العائم".

## الإصدار 1.1: التعرف عليه في Key Mapper
- وضع Shizuku صار يحقن ضغطة حقيقية (DOWN ثم UP) مع scancode ومصدر لوحة مفاتيح، بدل أمر `input` السريع.
- فيه إعداد "مدة الضغط" وحقل تجربة داخل التطبيق.
- إذا فشل الحقن المباشر يرجع تلقائياً لأمر `input` (وتشوف الطريقة المستخدمة في شاشة الحالة).

## الإصدار 2.0: أزرار متعددة ومخصصة
- تضيف أي عدد من الأزرار العائمة، وكل زر له اسم وحجم وإجراء خاص.
- الإجراءات: ضغط مفتاح (K، رفع/خفض الصوت، أي حرف أو KEYCODE)، أو ضغطة شاشة بإحداثيات.
- الأزرار تستخدم FLAG_SPLIT_TOUCH عشان تستقبل لمستك حتى لو إصبعك الثاني ماسك الأيم.
- ضغطة الشاشة تنحقن كنقطة لمس منفصلة (id=9) بنفس جهاز الشاشة، لتقليل احتمال فك الأيم (تجريبي، يختلف حسب الأندرويد واللعبة).
- لتحريك الأزرار: زر "تحريك الأزرار" في التطبيق أو في الإشعار.

## الإصدار 2.1: لمس خام (evdev) يندمج مع إصبع الأيم
- ضغطة الشاشة صارت تنكتب مباشرة في ملف شاشة اللمس `/dev/input/eventN` بنقطة (slot) إضافية، فيشوفها النظام كإصبع ثاني حقيقي بدون ما يقطع إصبعك الماسك.
- تشتغل عبر Shizuku (صلاحية shell) أو الروت. إذا فشلت يرجع للطرق القديمة تلقائياً.
- "اختيار الموقع من الشاشة" يلتقط الإحداثيات الخام مباشرة من الشاشة، فما يحتاج حسابات دوران.
- زر "فحص شاشة اللمس (تشخيص)" يعرض الملف والمدى وعدد النقاط. وفي شاشة الحالة تشوف آخر طريقة وآخر خطأ.
- خيار "ثبّت طالما إصبعك على الزر" يشتغل مع اللمس كذلك (للتثبيت على زر الإطلاق مثلاً).
